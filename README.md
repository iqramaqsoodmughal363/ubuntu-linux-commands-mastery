## 📋 Overview

This repository contains a comprehensive, categorized list of **115 essential Linux commands** (specifically for Ubuntu/Debian systems). It is designed to help beginners and intermediate users master the command line for system administration, security analysis, and daily tasks.

---

## ✨ Command Categories (Acts)

* **Act 1:** User & System Info (`whoami`, `uname`, `uptime`)
* **Act 2:** Directory & File Structure (`pwd`, `ls`, `mkdir`, `cd`)
* **Act 3:** Inspecting & Editing Files (`cat`, `less`, `nano`, `stat`)
* **Act 4:** User & Access Privilege Lockdown (`chmod`, `chown`, `sudo`, `useradd`)
* **Act 5:** Neutralizing Malicious Processes (`ps`, `top`, `kill`, `pkill`)
* **Act 6:** Searching for Malware & Backdoors (`find`, `grep`, `awk`, `sed`)
* **Act 7:** Network Traffic & Connections (`ping`, `ip a`, `netstat`, `ss`, `ssh`)
* **Act 8:** Storage, Disks & Backup (`df -h`, `du -sh`, `tar`, `zip`, `gzip`)
* **Act 9:** Services Management & Server Cleanup (`systemctl`, `crontab`, `free -m`, `reboot`)
